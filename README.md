# sonoildavid-media

Immagini dei caroselli PAESE RANDOM di @sonoildavid, servite via GitHub Pages
per la pubblicazione automatica su Instagram (workflow n8n "David - Pubblica carosello").

Le foto dei borghi vengono da Wikimedia Commons (CC BY-SA), con credito in ogni slide.
